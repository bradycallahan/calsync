# Privacy Policy — calsync

_Last updated: October 20, 2026_

calsync is a personal, self-hosted tool operated by Brady Callahan for his own use. It is not offered to the public, and the only Google account it is used with is the operator's own.

## What data calsync accesses

With the account owner's permission (granted through Google's OAuth consent screen), calsync accesses **Google Calendar data**: calendars and the events in them, including titles, times, locations, descriptions and related details. It uses the same kind of calendar data from the owner's iCloud account.

## How the data is used

The data is used for one purpose only: **copying events between the owner's Google Calendar and iCloud Calendar** so the two stay in sync. calsync creates, updates and deletes events in the owner's own calendars to do this.

## Storage

- calsync runs on a private server controlled by the owner.
- Calendar data passes directly between that server, Google and Apple. The server keeps only what it needs to sync: an OAuth token and a local record of which events have already been synced.
- No calendar data is sent to any other server, service or person.

## Sharing

calsync does **not** sell, share, transfer or disclose any user data to third parties. It does not use the data for advertising, analytics or AI/ML model training.

## Google API Services User Data Policy

calsync's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time from [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Deleting the calsync container and its data folder removes all locally stored tokens and sync records.
